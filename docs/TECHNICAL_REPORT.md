# Synthetic cloud data FinOps assessment

## Summary

This report records a reproducible assessment run over the repository fixture `tests/fixtures/assessment.json`, itself generated by a seeded synthetic multi-cloud telemetry generator (`cloud_data_finops.synthetic`, seed `20260901`). The input represents no organization, billing account, project, or production workload. It exists to demonstrate a specification-driven path from access review to evidence, findings, a report, and an executive deck.

The run produces 11 findings from 9 rules: five GCP BigQuery rules (excessive bytes scanned, repeated expensive queries, missing partition pruning, inefficient scheduling, reservation slot utilization) and four AWS rules (service/region cost anomaly, tag cost anomaly, idle resources, commitment/discount coverage). None estimate savings or authorize a cloud change; several deliberately withhold a monetary estimate because the fixture carries no pricing model. The full rule catalog, thresholds, and finding model are in [docs/rule-catalog.md](rule-catalog.md).

## Scope and method

The assessment specification declares both providers, a 30-day retention window, and fixture mode. The CLI validates the contract, runs a least-privilege preflight, generates a provider-specific access plan, routes fixture telemetry through injected adapters, evaluates nine policies, and writes structured findings, a Markdown report, PNG evidence cards, and a seven-slide PPTX deck.

BigQuery job metadata access uses `roles/bigquery.user` and `roles/bigquery.resourceViewer`, the roles Google documents for `INFORMATION_SCHEMA.JOBS`. Cost Explorer access is limited to `ce:GetCostAndUsage` and `ce:GetDimensionValues`. The repository rejects Owner, Editor, AdministratorAccess, wildcard actions, unrestricted Athena and S3 actions, and a CUR path without an approved prefix.

## Selected findings

### BQ-001: High-volume job without partition pruning

The fixture's largest job bills at or above the 10^12-byte threshold with `partition_pruned: false`. The policy reports the volume as a signal. The next action is to inspect partition filters and the query plan. The report does not infer a price because no price card, edition, location, or billing export was supplied.

### AWS-001: Service/region cost anomaly

A fixture AWS service/region cost exceeds 1.5x its declared baseline by at least USD 100. The policy reports the excess as an observed comparison. The next action is to inspect workload and tags before evaluating reservations or commitments.

### CMT-001: Commitment coverage observation

The fixture's commitment history is short of the twelve months required for a complete-evidence estimate, so this finding reports "No purchase recommendation" with `estimated_impact.value: null` and states exactly what evidence is missing, rather than estimating a dollar figure from partial data.

## Verification

`make check` runs formatting, lint, compilation, a secret scan, a documentation link check, 126 unit tests (contract, adapter, workflow, policy, access, safety, presentation, and regression), and the four core CLI commands end to end. `scripts/reproduce.py` independently rebuilds every artifact from the fixture and compares its SHA-256 against a versioned manifest.

## Limitations

The collectors use injected fixture clients. They do not authenticate to GCP or AWS, query table content, read a billing export, query CUR, or change infrastructure. The access plan documents a request boundary; it does not grant permissions. A live assessment requires a separate approved specification, provider credentials outside the repository, and adapter tests for the authorized resources.
