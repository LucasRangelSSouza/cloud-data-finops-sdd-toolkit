# FinOps report writing

Use this skill to write an English technical report from structured findings.

## Evidence discipline

Every technical claim must link to a finding, a source, or a documented calculation. Keep observed evidence, assumptions, recommendations, and limitations in separate fields. Preserve provider identifiers and units exactly as supplied. Do not invent pricing, savings, or customer context.

## Structure

Write an executive summary, scope, method, access boundary, findings, assumptions, limitations, and reproducibility steps. State whether the input is synthetic. A synthetic report must never be presented as a cloud assessment performed for a real organization.

## Style

Use direct professional English. Prefer precise verbs and concrete nouns. Avoid slogans, inflated claims, generic conclusions, and filler. End on the final supported fact.
